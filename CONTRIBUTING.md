# Contributing

Thanks for helping improve proxybench.

## Before opening an issue

- Search existing issues first.
- Never include proxy credentials, proxy lists, signing material, or other
  secrets.
- Use the bug form for reproducible problems and the feature form for scoped
  product suggestions.

## Pull requests

1. Open an issue before starting a substantial change.
2. Keep the change focused and follow `AGENTS.md`.
3. Run the checks listed in `AGENTS.md`.
4. Explain what changed and how you verified it in the pull request.
